Workflow en trois etapes

Installe le plugin, rattache ton site dans la console puis discute avec l'agent. Chaque action respecte les toggles et est journalisee.

Etape 1

Installer le plugin MCP

Active le plugin claudeus-wp-mcp sur WordPress. Il genere un identifiant dedie (URL, USER, PASS) sans partager ton mot de passe principal.

Telecharger le zip
Etape 2

Rattacher le site

Depuis la console, renseigne les champs URL / Identifiant / Secret. Les donnees sont chiffre es via AES-256 et verifiees via le service MCP.

Etape 3

Dialoguer avec l'agent

Lance des sessions chat, active les categories d'outils et laisse l'agent OpenAI executer les taches WordPress ou WooCommerce autorisees.
