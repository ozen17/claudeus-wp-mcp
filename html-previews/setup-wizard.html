📥 Étape 1/4: Télécharger le plugin

Installez le plugin MCP WordPress sur votre site

Le plugin MCP WordPress permet à Claudeus de communiquer avec votre site de manière sécurisée. C'est gratuit et facile à installer !

📥 Installation du plugin

1

Téléchargez le plugin WordPress MCP

💾 Le fichier téléchargé s'appellera "wordpress-mcp-plugin.zip"

2

Connectez-vous à votre WordPress

Accédez à votre tableau de bord WordPress en tant qu'administrateur

💡 Astuce: L'URL de votre tableau de bord est généralement https://votre-site.com/wp-admin
3

Installez le plugin

  1. Dans le menu de gauche, cliquez sur "Extensions"
  2. Cliquez sur "Ajouter" en haut
  3. Cliquez sur le bouton "Téléverser une extension"
  4. Cliquez sur "Choisir un fichier" et sélectionnez le fichier .zip
  5. Cliquez sur "Installer maintenant"

📸 Voici où trouver le menu Extensions :

┌─ WordPress ──────────┐
│ 🏠 Tableau de bord   │
│ 📝 Articles          │
│ 📄 Pages             │
│ 🎨 Apparence         │
│ 🔌 Extensions ◀━━━━  │  Cliquez ici!
│    ├─ Extensions     │
│    └─ Ajouter ◀━━━   │  Puis ici!
│ 👥 Utilisateurs      │
└──────────────────────┘
4

Activez le plugin

Une fois installé, cliquez sur le bouton bleu "Activer"

✅ Comment savoir si c'est réussi ? Un nouveau menu "MCP Settings" apparaîtra dans votre menu WordPress sous "Réglages". C'est là que vous irez à l'étape suivante !
